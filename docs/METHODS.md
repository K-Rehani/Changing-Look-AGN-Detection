# Methods and assumptions

## Frames, units, and quality

The individual SDSS spectrum supplies `flux`, `loglam`, `ivar`, and (if present) `and_mask` in HDU 1. The reader uses observed vacuum wavelength `lambda_obs = 10**loglam` in Å, and `lambda_rest = lambda_obs/(1+z)`. Standard SDSS `flux` is observed-frame `f_lambda` in `10^-17 erg s^-1 cm^-2 Å^-1`; positive `ivar` is its inverse variance. Zero/nonfinite `ivar`, nonfinite flux, and nonzero `and_mask` are invalid. `or_mask` bits can be selected by the reader's `reject_or_bits` parameter; their default treatment is not a complete survey quality policy. Check SDSS pipeline flags, sky residuals, extinction and flux calibration when reviewing a real pair.

Line and sideband windows are in **rest Å**. For each epoch independently, a weighted local straight-line continuum is fit in the two sidebands. The continuum-subtracted line is integrated by trapezoidal weights over the line window, with `d lambda_obs = (1+z) d lambda_rest`. Thus the reported integrated flux is in `10^-17 erg s^-1 cm^-2`. The rest equivalent width is `F_line / [(1+z) f_cont,obs(lambda_center)]` in Å when the continuum is positive. Formal line-flux variance sums per-pixel `w_i² / ivar_i` and the fitted continuum covariance projected into the integral. The continuum covariance is inflated when sideband reduced chi-square exceeds one. Independent noise is assumed, so these errors exclude pixel correlations and calibration systematics. A masked gap or missing sideband/line coverage produces an error instead of filling the gap.

The windows for Hβ, Hα, and Mg II are adapted from Guo et al. (2024), Table 3; their exact bounds are in `src/clagn_detection/lines.py`. The integrated Hα window includes narrow Hα and [N II], and Mg II may be contaminated by Fe II. The small [O III] 5007 measurement is only a relative-calibration diagnostic. A sufficiently significant >30% [O III] difference raises a warning; narrow lines are not assumed rigorously invariant. Spectral resolution, host subtraction, absorption, and the continuum model require inspection for real candidates.

## Broad-component review flag

For Hβ and Hα separately, weighted least-squares fits compare a linear continuum plus narrow Gaussian with the same model plus a broad Gaussian. Hα also includes tied [N II] Gaussians with a fixed 6583/6548 amplitude ratio of 2.96. The narrow centroid/width are shared within a complex. The broad component has constrained width and shift. A fit is marked as a broad detection for triage if it converges, improves BIC by more than 10, has formal broad-flux S/N at least 5, FWHM at least 1000 km/s, and avoids the width ceiling. A pair is flagged for review if detection status switches and the formal fitted broad-flux change exceeds 3 sigma. These are **heuristics**, not empirically calibrated selection cuts. A large difference in an integrated line score alone does not set the broad-transition flag.

The fitting model omits Fe II, host templates, wavelength-dependent calibration, complex/asymmetric profiles, instrumental line-spread functions, and correlated errors. It does not enforce tied physical behavior between epochs. BIC and covariance under this simplified model can be overconfident. Test the same pair with more complete fitting and inspect both raw spectra before interpreting a flag.

## Wavelength-grid handling and decisions

Each epoch's line integral and broad fit uses its native grid; there is no direct pixel subtraction for the ranking. The plot interpolates each epoch onto an overlapping rest-wavelength grid **only for display**, requiring adjacent valid pixels so gaps stay blank. Interpolated differences have no propagated uncertainties and are never used as detection statistics. This avoids assuming that SDSS observations share identical `loglam` samples.

The historical notes' exploratory area threshold of 1000 is not used. They describe taking an absolute value after integrating the signed two-epoch difference. This differs from integrating the absolute difference, because positive and negative changes can cancel in the first expression. Both have integrated-flux units and depend on the interval, continuum differences, sampling, noise, and normalization. Neither is a universal physical threshold. Current priority scores are formal change significances, also uncalibrated. A candidate requires credible broad-line evolution with adequate coverage and S/N, checked redshift, masks, calibration, host and continuum treatment, and visual review. Confirmation and physical interpretation require additional epochs and, where possible, photometry and multiwavelength constraints.
