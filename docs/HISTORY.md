# Project history

During summer 2025, I explored comparing repeat SDSS quasar spectra to search for possible changing-look AGNs. The project updates document DR16Q selection, a redshift cut below 0.8, repeat-observation metadata, oldest/latest spectrum comparisons, difference plots, an exploratory Hβ-region area score, and visual inspection. They record successive catalog counts of 750,414, 76,565, and 8,141, and a trial of roughly 200 pairs with 33 above the trial cut. These are counts recorded in the project updates, rather than independently reproduced results. Several spectrum plots from that work are included in the report.

The presentation also discusses line widths, equivalent widths, and AGN spectral types. Papers on double-peaked [O III], candidate binary AGNs, and recoiling black holes provided background; no completed searches on those topics are documented. The separate spectral-stacking and black-hole-kick project remains distinct.

The project was uploaded to GitHub in 2026. The accompanying package was reconstructed after the summer exploration, adding a reproducible command-line workflow, tests, and a controlled example. The report presents both the original exploration and the current analysis methods. The available project records do not include the original executable code or object-level data needed to reproduce the historical trial exactly. Current review flags prioritize spectra for inspection; real-survey validation and confirmed classifications remain future work.
