# Data and provenance

The input catalog is [SDSS DR16Q_v4](https://www.sdss4.org/dr17/algorithms/qso_catalog/) ([column model](https://data.sdss.org/datamodel/files/BOSS_QSO/DR16Q/DR16Q_v4.html)). It identifies quasars and lists primary and repeat plate–MJD–fiber observations. It does **not** contain the full one-dimensional flux arrays. Obtain the catalog directly from SDSS; keep its downloaded filename and checksum in your analysis record. The catalog is large (about 1.7 GB), and reading its redshift/repeat columns takes memory in addition to the mapped file.

Individual spectra are [SDSS `spec-PLATE-MJD-FIBER.fits` files](https://data.sdss.org/datamodel/files/BOSS_SPECTRO_REDUX/RUN2D/spectra/SPECTRA/PLATE4/spec.html). The optional `clagn fetch` uses [astroquery's SDSS API](https://astroquery.readthedocs.io/en/latest/sdss/sdss.html) with explicit plate, MJD, fiber, and release, caching the original returned FITS HDUs. It logs a SHA-256 hash per file. Keep the manifest, log, release, software versions, and the catalog checksum together for a reproducible run. A catalog observation may fail to resolve in a given release: inspect the failure log and the relevant SDSS archive. The downloader was not validated end to end against the live service in this repository's synthetic-only checks.

`select-pairs` chooses the earliest and latest positive, unique observation triples by MJD, omits pairs on the same MJD, and writes one pair per selected quasar. It uses `0 < Z < max_z` and `NSPEC >= 1`; the default `max_z` is 0.8. These cuts do not guarantee that every Balmer line is covered or that both spectra have enough good pixels. Analyzing a pair records missing coverage for each line. Selecting only DR16Q quasars also misses objects that were classified differently in another epoch.

`data/` and `results/` are ignored, as are FITS/NumPy binary files. Do not commit downloaded survey products without checking redistribution terms. The synthetic generator makes local FITS files in the same table shape used by the reader; its `SYNTH` header distinguishes them from survey data.
